# 💪 WorkoutApp

A **Flutter-based fitness application** built collaboratively, focused on clean UI, REST API integration, and Firebase backend.

---

## 📱 About the App

WorkoutApp helps users discover workout routines, explore exercise details, and track their fitness journey — all within a smooth, visually appealing mobile experience.

---

## ✨ Features

- 🎨 **Responsive & Clean UI** — Multiple screens designed with Flutter widgets for a consistent, polished look
- 🔄 **REST API Integration** — Fetches live workout routines, exercise details, and fitness data via ~4 REST APIs
- 🔐 **Firebase Authentication** — Secure login and user management
- 🗄️ **Firebase Firestore** — Real-time backend to store and manage user data
- 🧭 **Smooth Navigation** — Seamless screen transitions and consistent UX throughout

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Flutter (Dart) |
| Authentication | Firebase Auth |
| Database | Firebase Firestore |
| Data Source | REST APIs (×4) |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed
- Firebase project set up
- Android Studio / VS Code

### Setup

```bash
# Clone the repo
git clone https://github.com/your-username/workout-app.git

# Navigate into the project
cd workout-app

# Install dependencies
flutter pub get

# Run the app
flutter run
```
